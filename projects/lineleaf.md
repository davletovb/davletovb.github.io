## Purpose

Writing tools should make prose clearer without quietly changing what the writer means. Lineleaf explores conservative suggestions, explicit acceptance or dismissal, and reversible editing.

The intended experience includes spelling and grammar corrections, clarity rewrites, user-controlled tone changes and multilingual handling. Model execution runs through the shared [Seatline companion](/projects/seatline/).

## What remains uncertain

The repository contains product architecture and implementation planning, but its README still describes foundation-stage work. Individual editor compatibility and live provider integration require testing; the site does not claim universal editor coverage or production readiness.
