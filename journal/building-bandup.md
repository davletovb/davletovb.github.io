BandUp is an IELTS preparation project covering Listening, Reading, Writing, and Speaking. It brings together diagnostics, targeted drills, longer tasks, review, and AI-assisted feedback in a Telegram Mini App and web experience.

The product question is practical: what should a learner do next, and how can the interface make that step clear?

## Connect the session to a purpose

A diagnostic signal can help identify a weakness. A daily session can turn it into a bounded piece of practice. Review can connect an earlier mistake with a later opportunity to try again.

BandUp’s learning loop combines these elements:

- Diagnostics and skill-specific practice.
- Short drills alongside fuller Writing and Speaking tasks.
- Review cards, practice history, and progress surfaces.
- Feedback that can inform another attempt.

The design principle is that a mechanic should help the learner work on an IELTS-relevant weakness or measure relevant performance honestly.

## Give feedback a standard

Useful feedback needs to point to something the learner can act on. Scores need a separate standard of evidence.

Writing and Speaking evaluation require calibration before grades can be treated as reliable evidence of IELTS performance. That makes evaluation quality part of the product work, alongside interface and session design.

## Explore a more structured interface

Studio is an additional interface direction using the existing backend. It explores a learning workspace with more visible structure and room to adapt as the learner works.

The aim is to connect activities, feedback, and progress so that the learner can understand the path through them. Chat can be one interaction within that experience.

BandUp and Studio remain in development. Current work spans adaptive learning flows, assessment, content quality, and the interfaces that hold them together.
