# behruz.me

Source for [behruz.me](https://behruz.me), built by GitHub Pages with Jekyll.

- `index.md` — the homepage: intro, dated project list, research line, links.
- `journal.md` — the journal index, a dated list of entry titles.
- `_posts/` — one file per journal entry, named `YYYY-MM-DD-slug.md`. Give each a `title`, a short `description` and a `permalink: /journal/slug/`. New entries appear in the journal index automatically.
- `_layouts/` — `default.html` for every page, `note.html` for journal entries.
- `assets/css/site.css` — the only stylesheet. Light and dark follow the system setting.
- `CNAME`, `robots.txt`, `journal-redirect.html` — the custom domain, crawler rules, and a redirect from the old `/journal.html`.

The 2022–2023 journal entries keep their original wording.
